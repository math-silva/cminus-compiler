# C-Minus Compiler

This repository contains a compiler for the C-Minus programming language, implementing the key phases of compilation: Lexical Analysis, Syntax Analysis, and Semantic Analysis.

## Features

- **Lexical Analysis**: Tokenizes the source code, identifying keywords, identifiers, operators, and literals.
- **Syntax Analysis**: Parses the tokenized input, constructing a syntax tree and verifying if the code follows the grammar rules.
- **Semantic Analysis**: Ensures the correctness of variable declarations, type checking, and function calls.

## Usage

### Compilation

To compile the project, use:

```sh
make
```

### Running the Compiler

To execute the compiler on a C-Minus source file:

```sh
./cminus <source_code>
```

### Example

Compiling the `examples/gcd.txt` file:

```sh
./cminus examples/gcd.txt
```

The compiler will generate the following files:

```
output
└── gcd
    ├── symbol_table.txt
    └── syntax_tree.txt
```

The `symbol_table.txt` file contains the symbol table generated by the compiler, and the `syntax_tree.txt` file contains the syntax tree generated by the compiler.

## Project Structure

- `scanner.l` – Lexical analyzer written in Flex.
- `parser.y` – Syntax analyzer using Bison.
- `analyze.c` – Semantic analysis implementation.
- `symtable.c` – Symbol table management.
- `main.c` – Compiler entry point.

## Dependencies

Make sure you have the following installed:

- `flex` (for lexical analysis)
- `bison` (for syntax analysis)
- `gcc` (for compiling the project)
